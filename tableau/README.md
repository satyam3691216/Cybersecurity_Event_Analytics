# Tableau Dashboard — Cybersecurity Event Analytics & Threat Monitoring

## 1. Project Overview

This Tableau dashboard visualizes security events generated by the Automated Cybersecurity Event Analytics & Suspicious Activity Detection System.

The dashboard helps users understand security event patterns, compare risk levels, and identify areas requiring further investigation.

The project uses synthetic cybersecurity data for demonstration and educational purposes.

## 2. Dashboard Objectives

- Visualize the distribution of security risk levels.
- Compare average hybrid risk scores across risk categories.
- Analyze security events over time.
- Identify patterns in different types of security events.
- Present analytical findings in an accessible visual format.

## 3. Dashboard Visualizations

### 3.1 Security Risk Distribution

**Chart type:** Bar chart

**Purpose:** Displays the number of events associated with each risk level.

**Observed results:**
- Low risk: 985 events
- Medium risk: 15 events

These figures represent the current analysis results and may change when the dataset or detection process changes.

### 3.2 Average Hybrid Risk Score by Risk Level

**Chart type:** Bar chart

**Purpose:** Compares the average hybrid risk score for each risk category.

**Observed results:**
- Low risk: 13.31
- Medium risk: 43.66

The hybrid score combines rule-based risk scoring with anomaly scores.

### 3.3 Security Events by Type Over Time

**Chart type:** Multi-line chart

**Purpose:** Shows how different types of security events are distributed across hours of the day.

The visualization helps users compare event patterns and identify periods that may deserve further investigation.

## 4. Data Source

The dashboard was developed using CSV exports from the project's synthetic cybersecurity event data and analytics results.

The source data includes security-event attributes such as:

- Event ID
- Event timestamp
- Event type
- User ID
- Device ID
- IP address
- Location
- Authentication status

Risk-summary data includes risk categories, event counts, and hybrid risk score statistics.

## 5. Technology Stack

## 6. How to Open the Dashboard

1. Install Tableau Public.
2. Open the saved Tableau workbook.
3. If prompted, locate the CSV files used by the workbook.
4. Confirm that the data fields are mapped correctly.
5. Refresh the data if required.
6. Open the dashboard to explore the visualizations.

## 7. Important Limitations

- The project uses synthetic data rather than real production security logs.
- The dashboard's findings reflect the current dataset and scoring configuration.
- Anomaly detection results are not proof of malicious activity.
- The current risk distribution contains Low and Medium categories; no High-risk events appear in the displayed summary.
- The dashboard is an analytical prototype, not a production security monitoring service.
